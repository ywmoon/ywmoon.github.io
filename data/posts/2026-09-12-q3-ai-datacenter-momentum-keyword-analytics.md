    </h2>

    <p style='font-size: 1.05rem; line-height: 1.9; color: #334155; margin-bottom: 20px;'>

    </p>

    <h3 style='font-size: 19px; font-weight: 700; color: #1E293B; margin: 28px 0 14px 0;'>

    <h3 style='font-size: 19px; font-weight: 700; color: #1E293B; margin: 28px 0 14px 0;'>
      1.2 기사 1만 건당 정규화 지수 및 복합 모멘텀 산출 수식
    </h3>
    <p style='font-size: 1.05rem; line-height: 1.9; color: #334155; margin-bottom: 20px;'>
      기간별 모수 불균형을 엄밀하게 보정하고 실제 산업 현장의 관심도 가속도를 계량화하기 위해 수립된 수리 모델은 다음과 같습니다:
    </p>

    <div style='background-color: #0F172A; color: #F8FAFC; padding: 22px 26px; border-radius: 8px; margin: 24px 0; font-family: "Fira Code", Consolas, monospace; font-size: 0.96rem; line-height: 1.7;'>
      <div style='color: #34D399; font-weight: 700; margin-bottom: 8px;'>[식 1-1] 기사 1만 건당 정규화 출현 빈도(Normalized Frequency)</div>
      \text{NF}_{i, m} = \left( \frac{C_{i, m}}{N_m} \right) \times 10,000
      <br><br>
      <span style='color: #94A3B8;'>
      • $C_{i, m}$ : $m$월 데이터셋에서 키워드 $i$가 출현한 기사 건수 (단일 기사 내 중복 제거)<br>
      • $N_m$ : $m$월에 수집된 총 유효 기사 모수 ($N_{Jul} = 159,129$, $N_{Aug} = 105,390$, $N_{Sep} = 35,361$)<br>
      • 이를 통해 월별 수집량 차이에 관계없이 "임의의 기사 1만 건을 무작위 추출했을 때 해당 키워드가 등장할 통계적 기대 확률"을 산출.
      </span>
      <br><br>
      <div style='color: #34D399; font-weight: 700; margin-bottom: 8px;'>[식 1-2] 복합 모멘텀 가속도 지수 (Momentum Acceleration Index)</div>
      M_i = \left( \frac{\text{NF}_{i, Aug} - \text{NF}_{i, Jul}}{\text{NF}_{i, Jul} + \epsilon} \right) \times \log_{10}\left( C_{i, Aug} + 1 \right) \times \Phi_{burst}(i)
      <br><br>
      <span style='color: #94A3B8;'>
      • $\epsilon$ : 영분모 방지용 평활 상수 ($\epsilon = 0.1$)<br>
      • $\log_{10}(C_{i, Aug} + 1)$ : 보도량 모수가 극소수(예: 1건 ➔ 5건)인 노이즈 키워드의 과도한 변동성을 억제하는 볼륨 가중치<br>
      • $\Phi_{burst}(i)$ : 특정 주간(Weekly)에 일시적으로 보도가 폭발했는지를 측정하는 Kleinberg 버스트 계수
      </span>
    </div>

    <h3 style='font-size: 19px; font-weight: 700; color: #1E293B; margin: 28px 0 14px 0;'>

    </h3>
    <p style='font-size: 1.05rem; line-height: 1.9; color: #334155; margin-bottom: 20px;'>
      3분기 기사를 미디어 유형별로 교차 분석한 결과, 보도 프레임에서 뚜렷한 시각차가 확인되었습니다.
    </p>
    <ul style='margin: 0 0 20px 0; padding-left: 24px; font-size: 1.0rem; color: #334155; line-height: 1.85;'>
      <li><strong>IT·엔지니어링 전문지:</strong> 랙당 전력 밀도(150kW), 1.6T CPO 패키징, D2C 콜드 플레이트 마이크로 채널 유체역학 등 구체적 하드웨어 스펙과 표준 규격 논의에 75% 이상의 지면을 할애했습니다.</li>
      <li><strong>경제·금융 일간지:</strong> 빅테크 CapEx(2,200억 달러)의 분기 실적 회수 가능성, AWS의 36.7% 성장률, SMR 원전 파운드리 수주(두산에너빌리티), 해남 솔라시도 2.5조 원 투자 등 자본 흐름과 주가 모멘텀을 집중 조명했습니다.</li>
      <li><strong>종합 일간지 및 방송사:</strong> 수도권 154kV 변전소의 계통 접속 거부 사태, 한전의 송전망 포화 및 산업용 전기요금 인상, 지역 주민들의 전자파 민원 등 인프라의 사회적 갈등 요인을 핵심 이슈로 다루었습니다.</li>

      위 수식 체계와 다차원 미디어 프레임 필터링을 통해 29만 9,880건의 기사 원문으로부터 노이즈를 완벽히 제거하고 실제 2026년 3분기 산업 현장에서 물리적 투자와 엔지니어링 패러다임 전환을 주도한 핵심 키워드 20개를 정밀하게 추출할 수 있었습니다.

    <h3 style='font-size: 19px; font-weight: 700; color: #1E293B; margin: 28px 0 14px 0;'>
      4.1 네트워크 중심성(Centrality) 4대 지표 산출 수식
    </h3>
    <div style='background-color: #0F172A; color: #F8FAFC; padding: 22px 26px; border-radius: 8px; margin: 24px 0; font-family: "Fira Code", Consolas, monospace; font-size: 0.94rem; line-height: 1.7;'>
      <div style='color: #34D399; font-weight: 700; margin-bottom: 8px;'>[네트워크 그래프 중심성 수리 모델]</div>
      • 연결 중심성 (Degree Centrality): C_D(v) = \frac{\text{deg}(v)}{N - 1} = \frac{\sum_{u \ne v} A_{vu}}{N - 1}<br>
      • 매개 중심성 (Betweenness Centrality): C_B(v) = \sum_{s \ne v \ne t} \frac{\sigma_{st}(v)}{\sigma_{st}}<br>
      • 근접 중심성 (Closeness Centrality): C_C(v) = \frac{N - 1}{\sum_{u \ne v} d(v, u)}<br>
      • 고유벡터 중심성 (Eigenvector Centrality): C_E(v) = \frac{1}{\lambda} \sum_{u \in M(v)} C_E(u)
      <br><br>
      <span style='color: #94A3B8;'>
      • 특히 매개 중심성($C_B$)은 서로 다른 두 기술 영역(예: 전력망과 액체냉각, 반도체와 광통신) 사이에서 정보와 아키텍처 설계를 매개하는 '가교(Bridge) 노드'를 식별하는 핵심 지표임.<br>
      • 본 연구에서 매개 중심성이 0.35를 초과하는 노드는 복합 하이브리드 아키텍처(예: SMR-마이크로그리드-AIDC, CDU-D2C-지역난방)의 필수 병목 접점으로 기능함.
      </span>
    </div>
