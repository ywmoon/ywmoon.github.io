개념 정의</h2> <p style='margin: 0 0 12px 0;'><strong>비인간 신원(Non-Human Identity, NHI)</strong>이란 사람이 아닌 소프트웨어, 서비스 계정, API 클라이언트, 컨테이너, 그리고 자율적으로 동작하는 <strong>AI 에이전트</strong>가 인프라 자원에 접근할 때 부여받는 고유한 디지털 식별자(Identity)와 자격 증명 체계를 의미합니다.</p> <blockquote style='margin: 0; padding: 12px 16px; background: #EFF6FF; border-left: 4px solid #3B82F6; border-radius: 6px; color: #1E3A8A; font-size: 15px;'><strong>직관적 비유:</strong> 사내 출입증이 직원(인간)에게 발급되는 신원이라면, 물류 창고를 24시간 오가는 자율주행 지게차(AI 에이전트) 각각에 부여되는 고유 차량 번호판과 구역별 전자 통행권이 바로 NHI입니다.</blockquote> <p style='margin: 12px 0 0 0;'>과거에는 정적 API 키나 서비스 계정 비밀번호를 공유해 쓰는 경우가 많았으나, AI 에이전트가 코드를 직접 실행하고 외부 API를 연쇄 호출하는 환경에서는 각 에이전트 단위의 세분화된 신원 부여와 수명 주기 통제가 필수 인프라 요건으로 자리 잡았습니다.</p> </div> <div style='margin-bottom: 28px;'> <h2 style='margin: 0 0 14px 0; font-size: 20px; color: #0F172A; border-left: 4px solid #2563EB; padding-left: 12px;'>⚙️ 2. 작동 원리 &amp; 메커니즘</h2> <p style='margin: 0 0 12px 0;'>NHI 아키텍처는 <strong>모델의 판단을 신뢰하지 않고 인프라 경계에서 권한을 강제하는 제로 트러스트 원칙</strong>을 기반으로 동작합니다. 핵심 메커니즘은 크게 세 단계로 구성됩니다.</p> <ul style='margin: 0 0 16px 0; padding-left: 20px;'> <li style='margin-bottom: 8px;'><strong>단기 동적 자격 증명(Ephemeral Credentials) 발급:</strong> 영구적인 시크릿 키 대신 OIDC(OpenID Connect) 또는 SPIFFE/SPIRE 기반의 워크로드 증명(Attestation)을 통해 수분에서 수시간 단위만 유효한 임시 토큰을 발급합니다.</li> <li style='margin-bottom: 8px;'><strong>하드웨어 기반 신원 바인딩:</strong> 에이전트가 실행되는 가상머신이나 칩 단위의 격리 환경(예: 하이퍼바이저 오프로드 칩)이 워크로드의 무결성을 검증한 뒤에만 신원 토큰을 인계받아 탈취 및 위조를 차단합니다.</li> <li style='margin-bottom: 8px;'><strong>행위 기반 최소 권한 정책(Just-in-Time Scope):</strong> AI 에이전트가 특정 태스크를 수행할 때만 해당 API와 데이터셋에 대한 읽기/쓰기 권한을 일시적으로 열고, 작업 종료 즉시 회수하여 피해 반경을 격리합니다.</li> </ul> <div style='overflow-x: auto;'> <table style='width: 100%;
